# SmartChef · Entrega 1

Ionic 9 + Angular 22 (standalone). Ver rutas y estructura en `src/app/app.routes.ts`.

Arrancar: `npm install` y `ionic serve`. Móvil: `ionic build && npx cap add android && npx cap sync && npx cap run android`.

Pendiente: fotos reales en `src/assets/recetas/` + `CREDITOS.md`, capturas claro/oscuro, vídeo.
